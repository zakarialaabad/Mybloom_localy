## 📂 Before Running: Setup Image Folder

The ingredient seeder looks for images in `public/ingredients/`

### Quick Folder Setup

**Windows (PowerShell):**
```powershell
$ingredients = @('Mangue', 'Vanille', 'Noix de coco', 'Aloe vera', 'Pépins de raisin', 'Sésame', 'Amande', 'Jojoba', 'Arbre à thé', 'Oliban', 'Eau de rose distillée', 'Avocat', 'Karité', 'Cacao')
$ingredients | ForEach-Object { mkdir "public/ingredients/$_" -Force }
```

**Linux/Mac:**
```bash
for ing in Mangue Vanille "Noix de coco" "Aloe vera" "Pépins de raisin" Sésame Amande Jojoba "Arbre à thé" Oliban "Eau de rose distillée" Avocat Karité Cacao; do
  mkdir -p "public/ingredients/$ing"
done
```

### Then Add Images

Place image files in each folder:
```
public/ingredients/Mangue/image.jpg
public/ingredients/Vanille/image.png
public/ingredients/Noix de coco/image.jpg
... etc
```

## ⚠️ Troubleshooting

### "No image found" warning
- Check folder exists: `public/ingredients/{ingredient_name}/`
- Check image file is inside
- Check file is jpg, png, gif, webp, or avif

### Duplicate entries
- Seeds check for duplicates and skip them
- Run as many times as you want

### Seeder file not found
- Ensure file is in: `backend/database/seeders/`
- Exact class name: `MasterFrenchSeeder`, `CategorySeederFrench`, etc.

## 🎓 How Image Discovery Works

1. Looks in: `public/ingredients/{ingredient_name}/`
2. Finds first image file (.jpg, .png, .gif, .webp, .avif)
3. Stores path in database: `/ingredients/{ingredient_name}/image.jpg`
4. If not found, stores `null` (no warning, just continues)
