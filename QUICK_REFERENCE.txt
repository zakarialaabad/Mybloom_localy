## ✅ What Gets Imported

```
From JSON                  → Database
─────────────────────────────────────
brand                      → 1 brand
categories (5)             → 5 categories
type_produit (10+)         → 10+ product_types
ingredients (all)          → 15+ ingredients
products (31)              → 31 products
  ├─ img_main              → product_images (primary)
  ├─ variants              → product_variants
  ├─ faqs                  → product_faqs
  └─ ingredients           → ingredient_product (pivot)
```

---

## 🔄 Data Flow Example

```
Product: "Summer in Bali"
  • type_produit: "Body Butter" → links to product_types
  • category: "beurre" → links to categories
  • img_main: "/images/..." → creates product_images (is_primary=true)
  • variants: [{size:200, price:80}] → creates product_variants
  • ingredients: ["Sésame", "Pépins"] → links to ingredient_product
  • faqs: [4 items] → creates product_faqs
  • is_recommended: true → preserved in products table
```

## 🛠️ Common Commands

### Run Seeder
```bash
cd backend
php artisan db:seed --class=Database\\Seeders\\ProductJsonSeeder
```

### Run with Fresh Migration
```bash
cd backend
php artisan migrate:fresh
php artisan db:seed --class=Database\\Seeders\\ProductJsonSeeder
```

### Run with All Seeders (if added to DatabaseSeeder)
```bash
cd backend
php artisan db:seed
```

### Clear and Reseed Only Products
```bash
cd backend
php artisan truncate:tables products product_images product_variants product_faqs ingredient_product
php artisan db:seed --class=Database\\Seeders\\ProductJsonSeeder
```

### Check Seeded Data
```bash
cd backend
php artisan tinker

# Count products
>>> \App\Models\Product::count()
31

# Get first product with all relations
>>> $p = \App\Models\Product::first()
>>> $p->name
"Summer in Bali"
>>> $p->images()->count()
1
>>> $p->variants()->count()
1
>>> $p->faqs()->count()
4
>>> $p->ingredients()->pluck('name')

# Exit
>>> exit
```

## 📞 Troubleshooting

| Issue | Solution |
|-------|----------|
| File not found | Check `backend/database/products.json` exists |
| Syntax error | Run `php -l backend/database/seeders/ProductJsonSeeder.php` |
| DB error | Run `php artisan migrate` first |
| Migrations not run | Run `php artisan migrate:fresh` |
| Want to reset | Run `php artisan migrate:fresh` then re-seed |
