## 🌐 FRENCH LOCALIZATION STANDARDS

### Perfume-Specific Terminology
| English | French (Standard) | Moroccan Accent |
|---------|------------------|-----------------|
| Perfume | Parfum | Parfum |
| Fragrance | Fragrance / Parfum | Parfum |
| Scent | Senteur / Parfum | Parfum |
| Women | Femme | Femme |
| Men | Homme | Homme |
| Luxury | Luxe | Luxe |
| Authentic | Authentique | Authentique / Original |
| Free Shipping | Livraison Gratuite | Livraison Gratuite |
| Cash on Delivery | Paiement à la Livraison | Paiement à la Livraison |
| Best Sellers | Meilleures Ventes | Best-Sellers |
| In Stock | En Stock | En Stock |
| Out of Stock | Rupture de Stock | Rupture de Stock |

### E-Commerce Trust Language (Moroccan Market)
- "100% Authentique" (not just "Original")
- "Paiement à la Livraison" (huge in Morocco)  
- "Livraison au Maroc" (emphasize local focus)
- "Paiement Sécurisé" (security matters)
- "Satisfait ou Remboursé" (trust builder)
- "Service Client Disponible" (availability matters)

### Currency & Pricing
- Display prices in **DH (Dirham)** with symbol
- Format: `590 DH` or `590,00 DH` (no € symbol)
- Free delivery threshold: "À partir de 590 DH" (FROM 590 DH)

### Tone Guidelines
✅ **Professional + Approachable**: Not corporate-robotic  
✅ **Persuasive but not pushy**: Moroccan buyers value relationship  
✅ **Trust-focused**: Security, authenticity, reliability  
✅ **Action-oriented CTAs**: "Découvrir", "Ajouter", "Commander"  
✅ **Inclusive**: Gender-neutral where appropriate

## 🚀 IMPLEMENTATION RULES

### DO ✅
- Replace only TEXT content  
- Keep exact same HTML structure
- Preserve all styling classes (Tailwind)
- Test on mobile AND desktop after each phase
- Use French diacritics correctly (é, è, ê, ç, etc.)
- Maintain brand voice (elegant, trustworthy)
- Format numbers culturally (590 DH, not DH 590)

### DON'T ❌
- Remove or add HTML elements
- Change className values
- Alter component structure
- Modify navigation links (keep hrefs)
- Break responsive design
- Use Google Translate outputs without quality check
- Mix French and English in single UI element
